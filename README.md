# BIOTECH laboratory website

Open `home.html` in a browser to view the site. Home, About, Contact, Login, and Registration pages share responsive styling and navigation.

## Files
- `home.html`, `about.html`, `contact.html`, `login.html`, `registration.html`: site pages
- `styles.css`: shared visual styling
- `script.js`: mobile navigation and demo form behavior
- `images/`: product and laboratory photographs

Registration and login work locally in the browser using `localStorage`; they are a front-end demo, not secure production authentication. Contact submissions show a local confirmation and are not delivered to a server. Connect these forms to a secure backend before using the site with real accounts or messages.
